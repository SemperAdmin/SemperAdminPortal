## Scope

MARADMIN 184/26 announces the Navy Flight Demonstration Squadron (Blue Angels) is accepting enlisted Marine applications. The message supports the FY26 Blue Angels selection board listed in MARADMIN 224/26. Applicability is the Active Component.

## Audience

- Active Component enlisted Marines seeking Blue Angels assignment. Apply per the solicitation criteria.
- Career planners. Process applications through the unit Career Counselor.
- HQMC Manpower Management Enlisted Assignments (MMEA). Coordinates with the Blue Angels for selection.

## Action items

- Pull the application package requirements through the unit Career Counselor.
- Confirm obligated service through TFRS.
- Email the application package to Blue Angels POC (A). Build it on the CNATRAINST 1301.4P template with the enclosures listed in paragraph 4.

## Board timeline

MARADMIN 224/26, the CY2026 SNCO selection board schedule, lists the FY26 Navy Flight Demonstration Squadron (Blue Angels) board with an application window of 2026-11. This message sets a different window. Applications were due no later than 2026-05-20 and selection results were due no later than 2026-06-01, so the window is closed. The 2026-11 row in MARADMIN 224/26 conflicts with this message. The portal's SNCO selection boards page carries the same timeline.

## Connection to Marine Corps doctrine

- MARADMIN 224/26. CY2026 SNCO Selection Boards. Lists this message as the application solicitation with a 2026-11 window in conflict with the 2026-05-20 deadline in this message.
- CNATRAINST 1301.4P. Application procedures template for the Blue Angels package.
- Total Force Retention System (TFRS). Obligated service verification.

## Status

Signed 2026-04-23. Originator CMC Washington DC MRA MM. Applicability is the Active Component. Active for the FY26 Blue Angels selection cycle. Verification caution.
