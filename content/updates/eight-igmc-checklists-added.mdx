Eight functional area checklists with an S-1 or command owner join the 14
already on the portal. Every page was built from the DOCX on
igmc.marines.mil pulled 11 September 2026 and carries the item codes,
questions, and references as published.

| FA | Checklist | Category | Items |
|---|---|---|---|
| 1040 | Career Planning Program | CoRE | 30 |
| 1700.23 | Request Mast Procedures | CoRE | 9 |
| 5040 | Command Inspection Program | CoRE+ | 16 |
| 1700.37 | Personal Financial Management Program | CoRE | 7 |
| 1742.1 | Voting Assistance Program | CoRE | 52 |
| 1700.31 | Transition Readiness Program | CoRE | 9 |
| 5512 | Identification Cards | Non-CoRE | 15 |
| 5110.1 | Postal Affairs, Military Postal Activity | CoRE+ | 112 |

Inspector guides for these eight do not exist yet. Pages show the checklist
only until the SME rebuilt guides arrive.
