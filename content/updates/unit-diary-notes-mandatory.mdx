PAA 03-26 took effect 1 October 2026. The portal reflects it on 20 October, so
units skipping the notes since 1 October are already out of step.

The advisory answers an Independent Public Accountant finding. The Research
Diary Report certification statement implies a review but does not document
one. The Notes tab at the bottom of each unit diary now carries the evidence.

- Preparers annotate each submission and each resubmission after corrections.
- Reviewers annotate each forward and each return. The Reviewer role stays optional.
- Certifiers annotate each return for correction and annotate again before certification.
- Every annotation starts with a YYYYMMDD date. Append each new annotation to the existing note, separate it with a forward slash, and never delete or overwrite a prior one.

The rule covers Unit Diary Notes only. Transaction User Notes, Transaction
System Notes, and Diary Feedback Report Notes sit outside it unless otherwise
specified. The MCTFS PRIUM update is still forthcoming, so the advisory is the
controlling text today.
