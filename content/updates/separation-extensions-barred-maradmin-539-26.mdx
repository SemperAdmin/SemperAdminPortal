MARADMIN 539/26 removes paragraph 11, Eligibility for Extension, from
MARADMIN 189/26. Commands no longer submit, endorse, or approve extension
requests, NAVMC 10274 included, to allow separation processing under
MARADMIN 189/26. A Marine reaching EAS before proceedings finish separates
on the scheduled EAS.

The rule covers MARADMIN 189/26 processing only. Extension rules for other
separation bases are unchanged.

The message does not state how the SPD code or involuntary separation pay
apply when EAS arrives first. Commands with a Marine in this position get
the answer from MPO before EAS.
