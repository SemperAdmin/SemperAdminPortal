The Leave, Liberty and Administrative Absence checklist published 3 September
2025 asks 11 questions. The portal page showed 7. The source document places
items 0108 through 0111 after the main table, and the import script only read
table rows. The page header claimed 11 items the whole time.

Restored items.

- 0108. Marines execute Active-Duty Parental Leave in increments of at least
  7 days. DoDI 1327.06 and MARADMIN 051/23.
- 0109. Leave is charged when a Marine checks out on a non-duty day.
  DoDI 1327.06 section 5.1.b.(1).
- 0110. Procedures exist for convalescent leave following childbirth or
  perinatal loss. DoDI 1327.06, BUMED NOTE 6000, MARADMIN 129/23.
- 0111. Procedures and requirements exist for allocating bereavement leave.
  DoDI 1327.06 section 3.11.j.(5), MARADMIN 220/23.

Any unit self-inspection built from the portal page before today missed four
questions an IGMC team will ask. Re-run the self-inspection against the full
list. The import script now reads body paragraphs after the table, so the
next pull holds all 11.
