The portal covered hardship discharge and PCS mechanics separately and left
the humanitarian path between them uncovered. The new page closes it with
the rules read straight from the ACTSMAN.

Three outcomes exist, and the 36-month rule decides which one applies.
A problem running past three years belongs in a hardship discharge
conversation, not a transfer request. The page also corrects a common
misread of reenlistment code RE-3C. The code is administrative, and it
comes off by a second Page 11 entry once the Marine reports the situation
resolved.
