AutoSAAR carried the MCTFS manpower system access request from the user through
the supervisor and security manager to MISSA, which validated and routed to TSO
Mainframe Security for provisioning. PAA 02-26 retired it. Commands stop
submitting new MCTFS end-user requests through AutoSAAR, legacy email, or a
locally routed DD Form 2875 after 17 September 2026. Any request not approved by
then requires resubmission in DoD E-ICAM on or after 21 September 2026.

Use the DoD E-ICAM entry instead for create, modify, and revoke requests. Route
questions about MCTFS roles, supporting documentation, functional approval, or
mainframe account status to the supporting MISSO.
